# 선택 전략 개발 및 1분봉 검증 결과

**현재 실행한 두 분봉 전략에서 거래당 수수료 전 4bp의 edge는 발견되지 않았다.** 돌파 매매는 기존보다 거래 수가 크게 늘었지만 가격수익부터 음수다. 성과를 본 뒤 시간·진입·TP·SL 파라미터를 조정하지 않았다. 모든 결과는 이미 접근한 과거 데이터에 대한 탐색적 검증이며 새로운 OOS 성과가 아니다.

## 개발 범위와 상태

| 전략 | 구현 | 실데이터 검증 상태 |
|---|---|---|
| 후보 2: 매도 압력 흡수·회복 | 신호·충격 전 VWAP 목표·충격 저가 손절·체결 엔진 | 틱 기간 부족으로 성과 평가 보류 |
| 후보 3: 압력 변화와 압축 돌파 | 신호·박스 폭 목표·박스 저가 손절·재진입 상태 | 틱 기간 부족으로 성과 평가 보류 |
| 시총 상위 3종목 수요 대비 ETF 반응 | 일별 유니버스·과거 20일 예측 회귀·예측가격 목표·5분 저가 손절 | 과거 일별 시총과 해당 종목 분봉 부재 |
| 분봉 압축 돌파 | 구현·실행·거래 원장 출력 | 실패 |
| 장초→장말 포지셔닝 | 252일 장전 회귀·예측가격 목표·직전 30분 저가 손절·실제 종가 검증 | 실패·저빈도 |
| 전일 외인 상위 30% / 기관 순매수 하위 30% 추세 | 코스피200 전체 현물 순매수의 과거 252일 순위·다음 날 돌파 | 코스피200 수급 원자료 부재 |

수급 조건은 종목 간 순위가 아니다. 코스피200 합산 외인 순매수는 양수·과거 상위 30%, 기관 순매수는 음수·과거 하위 30%로 고정했다. 값은 전일 것을 사용하고, 분포는 그 전일까지의 252거래일로 계산한다. KOSPI 전체·ETF 자체 수급이나 선물 수급을 대신 사용하지 않았다.

## 수집과 데이터 검증

VibeTrading의 `KiwoomAuthClient` 인증·토큰 캐시를 재사용하는 별도 연구 수집기를 작성했다. 계좌·주문 조회 없이 KRX 차트 데이터만 받았다. live 수집 코드를 변경하지 않았다.

- 1틱 차트: 마지막 배치 2,000페이지, **1,800,000행**, 2026-09-16 11:16:04~2026-10-07 09:31:05. 첫/마지막 부분 일자를 제외한 연속매매 공통 완전 일자는 별도 감사 파일에 기록한다. 120일 기준에 미달한다.
- 1분봉: 104페이지, **92,875행**, 2025-10-01~2026-10-06. 종료 상태는 `SERVER_END`였다. 다른 기준일·종목까지 포괄하는 보유기간 보장은 아니다.
- 일봉: 1,200행을 받아 필요한 2022년 11월 이후 구간을 보관했다. ETF 분봉의 종가 이벤트를 일봉 종가와 대조하는 데 사용했다.
- 장중 소스 대조: 기존 Toss 분봉을 −1분 이동하면 87,208개 공통 장중 봉의 OHLC와 거래량이 모두 키움과 일치했다. 15:30은 연속매매 봉과 다르게 처리했다.
- Toss 15:30 가격과 키움 일봉 종가는 943일 중 940일 일치했다. 불일치 3일은 수능일로 정규 09:00 개장 조건에서 이미 제외된다. 장말 전략에는 독립적으로 확인된 실제 종가만 사용한다.
- 틱과 분봉의 장중 거래량도 대조했다. 9월 17일~10월 6일의 4,180개 연속매매 분에서 거래량이 모두 일치했다. 따라서 이번 틱은 짧은 기간의 구조 점검에 쓸 수 있지만 장기 성과 검증 자료로는 부족하다.

틱은 설정한 페이지 한도에서 멈췄다. **이를 키움의 최대 틱 보유기간이라고 해석하면 안 된다.** 체크포인트를 저장해 동일 배치를 이어 받을 수 있도록 했다. 현재 확보 자료가 사전 기간 기준을 통과하지 못했으므로 이번 실행은 분봉 대안을 사용한다.

키움 과거 1틱 차트에는 native aggressor side가 없다. 체결 방향은 동일 초의 가격이 하나인 경우에만 tick rule proxy로 계산하고, 여러 가격이 같은 초에 발생하면 방향 미상으로 처리한다. 동일 초·가격·수량 체결을 임의 중복 제거하지 않는다. ETF 거래량 증가나 이 proxy를 리테일 순매수로 해석하지 않는다.

기존 ETF 분봉 2022-11-23~2026-10-06의 943일을 활용했다. 늦은 개장·정상 청산 봉 부재 등 10일을 제외하고 933일이 남았다. 돌파 전략은 앞 20일을 정규화에 써서 평가일이 913일이다. 장말 모델은 독립 종가 검증·252일 회귀 준비를 거친 679일을 평가한다. 거래가 없는 날도 분모에 포함한다.

## 사전 고정 조건

1분 신호, 완료된 직전 5분 박스, 이전 20거래일 동일 5분 시간대의 범위·거래량 중간값을 사용한다. 신호가 종료된 뒤 한 분을 기다리고 다음 분 시가로 매수한다. TP는 박스 고가+박스 높이, SL은 박스 저가−1틱이다. 남은 목표 여력이 6bp 미만이면 체결을 거부한다. 이는 수수료 4bp와 기본 슬리피지 2bp를 넘는 목표 여력을 요구하는 것이며, 거래당 기대수익 4bp를 보장하는 조건이 아니다.

TP는 목표를 1틱 넘는 가격 범위가 관측돼야 인정한다. 동일 봉 TP/SL은 SL 우선, 손절 갭은 불리한 시가로 체결한다. 한 전략에서 한 포지션만 허용하고 같은 봉 청산/재진입을 금지한다. 신호가 꺼졌다가 다시 켜져야 재진입한다. 일반 전략은 보유 시간과 관계없이 15:19 시가로 장종료 정리한다.

장초 연구의 원 정의는 **전일 종가→09:30**이며 overnight를 포함한다. 최근 252일로 같은 날 마지막 30분 수익률을 예측하고 예상 상승이 6bp 이상인 날 15:00에 진입한다. TP는 예측 종가, SL은 14:30~15:00 저가−1틱이며 미청산은 실제 15:30 종가로 정리한다. 한국 ETF에서 이 효과가 약하다는 [APAC 후속 연구](https://researchmgt.monash.edu/ws/portalfiles/portal/519509174/494419119_oa.pdf)와 일치하는지를 검증하는 보조 가설이다. 하루 여러 번 거래하는 전략으로 취급하지 않는다.

## 연구 판단

분봉 압축·거래량 증가·돌파만으로 공급 소진과 지속 수요를 식별하기 어려웠다. 이 버전은 회전율 요구에 상당히 가까워졌지만, **수수료를 없애도 가격수익이 음수**여서 거래 실행을 개선하는 것만으로 목표를 달성할 수 없다. TP 배율이나 손절 폭을 같은 표본에서 여러 번 바꿔 구조적 손실을 숨기는 방식으로 진행하지 않는다.

선택한 후보 2·3의 다음 검증은 매도 압력 대비 가격이 버티는 정도, 새로운 매수 압력 대비 가격 충격이 커지는 정도가 이후 ETF 가격을 설명하는지에 초점을 둔다. 짧은 틱과 VibeTrading의 선물 호가/체결은 이 가설의 구조 점검에 사용할 수 있다. 해당 짧은 기간에서 여러 파라미터를 선택한 뒤 장기 검증 성과로 제시하지 않는다.

시총 전략은 과거 날짜별 구성 종목과 동시 현물 반응이 있어야 별도 경제 정보를 추가할 수 있다. 현재 상위 종목을 과거에 소급하면 평가를 왜곡하므로 자료 없이 결과를 만들지 않았다. 외인·기관 전략도 코스피200 현물 합산 수급 자료 확보 후에만 실행한다. 사용자가 이번에는 확보 ETF 자료부터 검증하기로 선택한 상태다.

## 실행과 산출물

고정 명세: `intraday_v2_spec.json`, `intraday_v2_spec.md`. 실행기는 새 틱 자료가 120개 완전 연속매매 일자를 통과하면 후보 2·3을 선택하고, 부족하면 분봉 대안을 선택한다. 시총/수급 파일은 존재하고 검증을 통과할 때만 해당 전략을 추가한다. 성과로 전략을 자동 선택하지 않는다.

```powershell
python -m unittest test_intraday_v2.py test_intraday_bracket_backtest.py
python intraday_v2_backtest.py
python verify_intraday_v2_outputs.py
```

일별 시총 자료가 확보됐을 때의 후속 파이프라인:

```powershell
python prepare_intraday_v2_data.py --caps historical_kospi_caps.csv
python collect_kiwoom_research.py --kind minutes --universe kiwoom_research_data/daily_top3_universe.csv --max-pages 150
python prepare_intraday_v2_data.py --assemble-members
```

시총 입력은 `date,symbol,market_cap,market,security_type,full_universe`이며 KOSPI 보통주 전체를 포함해야 한다. 전일 전체 시총 자료가 없는 날은 이전 유니버스를 이월하지 않는다. 수급 입력은 `kiwoom_research_data/kospi200_investor_daily.csv`의 `date,foreign_net_amount,institution_net_amount,scope`이며 `scope=KOSPI200_SPOT`만 허용한다.

백테스트 결과는 `backtest_intraday_v2/`의 거래 원장·월별 수익·신호·거부 주문·제외 일자·모델 학습일자·입력 SHA256·검증 결과에 보관한다. 49개 테스트가 기존/신규 엔진의 지연, 동일 봉 손절, TP 접촉, 데이터 공백, 미래 정보 차단, 일별 유니버스 전환, 수급 범위·시점을 검증한다. 거래 원장 전체의 손익과 실제 봉 가격도 별도 대조한다.

1분 OHLC와 고정 슬리피지는 호가 스프레드·대기열·시장 충격의 실측을 대신하지 못한다. 이 제약은 결과의 실거래 재현성에 영향을 주며, 음수 가격수익을 양수로 해석할 근거가 되지는 않는다. 여러 가설을 같은 과거 자료에서 평가했으므로 독립 신규 기간의 검증이 남아 있다.
